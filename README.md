# 법령 MCP 실무 프롬프트 20선

안양대학교 국비교육 특강(2026. 8. 20) 배포 자료.
AI가 국가법령정보(법제처)를 직접 조회하게 만든 뒤, 실무에 바로 쓰는 프롬프트 모음입니다.

**🔗 https://kjs369369.github.io/law-mcp-prompts20/**

## 구성

| 분류 | 수 | 내용 |
|---|---|---|
| ① 기본 | 4 | 조문을 정확히 가져오기 |
| ② 부서별 | 8 | 인사·노무 / 계약·구매 / 총무·안전 / 개인정보 / 마케팅 / 기획 / 영업·CS |
| ③ 문서 작성 | 4 | 근거가 달린 검토보고서·공지문·회신문·체크리스트 |
| ④ 심화 | 4 | 법령 비교 / 용어 정의 / 역질문 / 자기검증 |

## 선행 조건

프롬프트는 **법령 MCP가 연결된 상태**에서 작동합니다. 연결 전에는 AI가 기억에 의존해 답하므로
조문 번호나 내용이 틀릴 수 있습니다.

- 설치 방법: https://koica-law-mcp.vercel.app/
- OC 키 발급(무료·즉시): https://open.law.go.kr

> 조회 전용 도구이며 법률자문이 아닙니다. 최종 판단은 원문·소관부처 유권해석·전문가 자문을 따르십시오.
